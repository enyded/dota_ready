Dota Ready connects one Android device to one Windows PC so the user can receive a Dota 2 ready-check notification and request acceptance remotely.

Data processed

The service processes randomly generated installation identifiers, device and PC public keys, the PC name supplied by Windows, pairing status, online/Armed status, match-event identifiers and timestamps, requested actions, and execution results. The production hosting provider may also process ordinary network metadata such as IP addresses and request timestamps in access or security logs; document the deployed provider here: [HOSTING AND LOGGING DETAILS].

The app does not upload Dota screenshots or captured pixels. Detection remains local on the Windows PC. The Android app does not request direct camera permission and does not store QR images; it receives only the scanned one-time pairing value from the system scanner. The current app contains no advertising SDK or product analytics SDK.

Purpose and sharing

Data is used only to authenticate paired installations, relay connection state and match events, prevent replay, diagnose service operation, and deliver the requested result. It is not sold. It is disclosed only to infrastructure providers required to operate the service or when legally required. List production processors here: [PROCESSORS].

Storage and security

Android private keys are generated in Android Keystore and are not sent to the backend. The Windows Agent pins the backend command-signing public key. Pairing codes are random, one-time, expire after three minutes, and are stored by the backend as hashes. Production clients require encrypted HTTPS/WSS transport.

The current backend records installations, revoked pairing records, match events, and commands in its database and has no automatic deletion schedule. Before public release, set and state the production retention period here: [RETENTION POLICY]. Local Android history and pairing settings remain on the device until app data is cleared or the app is uninstalled.

User choices and deletion

The user can Disarm event delivery or Unpair the phone and PC in Settings. Unpairing revokes access but does not currently erase historical backend records. To request access or deletion, contact support.d2r@gmail.com. Document and operationally verify that request process before public release.

Children and changes

The service is not directed to children. Material policy changes will be published at the same stable URL with a new effective date. Questions may be sent to support.d2r@gmail.com.
